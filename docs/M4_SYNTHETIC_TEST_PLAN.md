# M4 synthetic operator test

The public demo shop is the isolated synthetic environment for M4 operator testing.

Target dataset after reset:
- 6 synthetic artists
- 1,200 synthetic customers
- varied styles, spend, appointment counts, cancellations and no-shows
- 5 current OPEN gaps with different styles/prices
- deterministic high-signal customers embedded for known scenarios
- no real customer contact data

The operator must label the environment synthetic. Demo activations must never contact external recipients; they create a simulated guarded offer and event instead.
